# Muted-string rhythmic attacks for electric styles

A fully damped/dead-string attack is not a pitched palm-muted note and not a rest. The implemented bounded extension represents an optional `mutedAttack` with explicit sorted unique strings and direction, with no fret or MIDI placeholder. It remains display/reference/self-practice only in the first contract, avoiding claims that the pitch detector assesses noisy chord scratches. Ordinary event encoding remains unchanged.

Selected event representation: note kind + positions empty + explicit mutedAttack (mutually exclusive ordinary pitches/harmonic/moving techniques/sustain). Validation must enforce exactly one note source, 1–6 unique strings, no fret metadata, no non-note use. Exercise graded validation rejects the event even in mixed phrases. Canonical sounding targets are empty. Implementation review covers every noteCount/first pitch consumer rather than assuming note always has a pitch.

Resolver retains physical muted strings under tuning/region choice; no invented transposition. Fretboard selection highlights mute crosses for affected strings, not open pitches. TAB displays x on affected strings, shared in compact/full modes. Staff uses an unpitched cross at fixed percussion position with timed stems/beams, no MIDI/accidental and no false rest. Text says muted attack plus strings; not an empty sounding-note sentence. Reference uses deterministic short noise bursts, separate from the click and bounded/no allocations in callback. Phase/index invariance across chunks/seeks/loops; practice reference stays silent as usual.

First use: funk-style pitched short chords, explicit offbeat dead attacks and rests. Chord/gesture/timbre assessment remains self-reported. Validate all tuning/neck variants, role persistence, invalid metadata, scored practice rejection, reference silence/rest distinction, original ordinary history, notation/VoiceOver and signed root Release. Do not reuse palmMuted since it intentionally retains a definite target pitch. Implementation and tests preserve these boundaries; see the authoring contract and same-agent review.
