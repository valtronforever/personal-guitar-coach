## Findings and fixes

- Stable-note quality intentionally rejects moving pitch. Added a separately versioned periodic trace using the same detector window and input clock, while preserving stable-sustain/onset behavior. Worker and attempt buffers are bounded; trace loss interrupts. Silence/noise/clipping and unsupported tempo/range remain distinct from wrong playing.
- A first accuracy assertion incorrectly sampled a sharp ramp/plateau boundary as instantaneous pitch. The 4096-sample window blends roughly the last 47 ms at 44.1 kHz. The test now asserts the constant-slope interior and the settled destination separately; production phase assessment excludes 60 ms at boundaries rather than concealing this limitation with a wider accuracy claim.
- `PitchBend` authoring validates fretted monophonic notes, 1–2 semitones and ordered in-note phases. The fingering resolver excludes open-string candidates for bends. Independent tests verify all lesson positions, pitches, durations and targets across 8 tunings × 5 neck sizes; the reference and target move together.
- Synthetic preview integrates changing frequency analytically, with exact chunk/seek checks and no per-sample point-array allocations. Ordinary reference waveforms remain unchanged; practice emits no guitar reference.
- Spectral-flux observations inside a bend cannot establish repicking. They remain in immutable evidence but are excluded from extra-attack penalties, uncertainty totals, rest recommendations and stored summaries. Initial attacks and observations in subsequent rests retain ordinary grading. Interval/ID lookups are built once and result exclusions cached, avoiding repeated nested scans in views/AI exchange.
- Every phase needs at least 80% known evidence. Target/return omissions cannot hide behind a longer correct phase because phase weights are equal. Saved results contain signed pitch error, silence/unknown coverage and the raw derived curve. Offset/late fixtures establish single application of latency. Physical motion and repicking are explicitly self-observed.
- AI response validation originally recognized only prompt v1. Bend exchanges now use validated v2 plus explicit unscored observation IDs; tampering is rejected. Both raw traces are stripped from CLI prompts. A maximum two-trace local-JSON fixture exceeds the old 16 MB cap; 24/28 MB request/response bounds retain headroom without changing CLI output limits or initiating provider calls.
- Course-wide “healthy silence” fixtures required an explicit silent contour, just as sustained-note fixtures already did. Missing contour correctly remains insufficient signal. Fixtures now preserve the original zero-score/history/retry assertions with valid synthetic silence; catalog counts updated to 62 total/56 visible.
- Offline 600px Ukrainian light and English dark curve renders show distinct dashed/solid paths, beat/cents axes and real gaps; localized accessibility names amount and return. These artifacts are SwiftUI layout evidence, not a native app/VoiceOver or real-guitar pass.
