# Lesson fretboard position — local review

Date: 2026-09-12. Reviewer: the implementing agent (same-agent review, not independent).

Scope: optional lesson region, pure interval resolver and complete-lesson availability, reader/visuals/preview/practice handoff, bookmark persistence, immutable attempts/retries/comparison, en/uk presentation and authoring contract.

Findings and fixes:
- Translating every original fret would change the key. The resolver instead keeps each tuning-adapted sounding MIDI, including octave, and selects another valid string/fret within the requested region. It retains the existing chord voice/span constraints and shared arpeggio mapping. Physical-pattern lessons reject this operation.
- A region valid for the selected fragment can fail elsewhere in the lesson. Availability resolves every exercise and displayed shape, using the selected 19/20/21/22/24-fret limit. Impossible options are omitted rather than silently moving notes an octave. Golden C Standard major near fret 7 uses strings [6,6,5,5,5,4,4,4] and frets [8,10,7,8,10,7,9,10] ascending. The corresponding Drop scale cannot fit frets 7–11; unavailable selection and explicit recovery are tested. Wide-range lessons can have no alternate five-fret region.
- Restoring a bookmark whose region fails under the new tuning initially lost its selected step because the fallback source has an older version. Restoration now checks the declared adapted teaching version, retaining the step even in the unavailable state. Resetting Original preserves reading status. Legacy bookmarks/references decode without a region, and stale lesson-version region selections are not reapplied.
- Practice could otherwise be refreshed with the default fingering or retries could be re-resolved. Fresh requests carry the position through instrument refresh; archived requests retain the exact exercise, tuning and region. Current preflight rejects a region/exercise mismatch before audio starts. An active synthetic attempt interrupted by a new position records changedExercise and the old configuration; the next selection clears physical confirmation.
- Two region choices may produce identical positions, so exercise equality alone does not identify the selection. Comparison additionally requires equal region metadata. The reader explicitly stops preview on region changes even when the resolved exercise is equal; different exercises also stop/reset PreviewModel. Playback tests verify the next transport uses the changed positions with identical pitches and synchronized active-event positions.
- Incompatible tuning can occur with Original as well as a saved region. The reader only claims a position-specific failure when a region is actually selected, and always provides a way to choose Original/another available region. Practice offers a return-to-lesson action. No fret inference from audio or fingering comfort guarantee is introduced.
