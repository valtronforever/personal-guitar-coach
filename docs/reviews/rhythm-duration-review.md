# Rhythm notation and sustain — local review

2026-09-16. Same-agent review, not independent. Scope: dotted/tied staff fragments, complete-note practice ranges, opt-in stable-pitch coverage, a substantive bilingual lesson and archived/AI evidence compatibility. This is a full-curriculum increment, not completion of all 128 topics.

## Findings and fixes

- A written tie must not generate a new musical event. Added typed fragment identity `(eventID,startTick)` for notation/focus, retaining canonical event IDs for selection, preview, tuning adaptation and assessment. Accidental continuity across a tie does not suppress the accidental of a later fresh attack. Dots/rests and ties use distinct rendering/accessibility semantics.
- A bar selection, retry or pause could cut a long note. Range expansion now includes whole events (including rests); feedback chooses legal windows, with a full-range fallback for very long ties. UI explains expansion. An exhaustive simple-meter grid test conserves duration; a waveform test confirms there is no second attack at the barline.
- Whole-window silence detection left an artificial uncertain tail after release. Sustain now uses local raw-input RMS around its window-center timestamp with DC removal, rather than the high-pass filter tail. Clipping/invalid input stays uncertain. A genuine boundary remains: 48 kHz A1, 0.5 s target stopped at 0.25 s, has 24% ambiguous coverage. The 20% quality limit is retained and this fixture explicitly expects no score. We did not lower confidence requirements to make every synthetic example score.
- Added author opt-in, a bounded/versioned 50 Hz trace and a separate stable-pitch-coverage metric. Wrong pitch is not silence; uncertainty is not a playing error. Matched attack timing anchors duration, with no double latency compensation. This does not certify exact release time, palm muting or physical string/finger technique.
- Results previously annotated a correct attack as matched even if sustain failed. Sustain failures now receive a distinct hourglass/text annotation; uncertain sustain receives the uncertainty marker. Per-note coverage/silence and aggregate eligibility are distinct.
- New default-false event flags would change canonical JSON and break archived coach digests. Encoding omits false; historical parameter versions 1/2 and absent sustain evidence remain readable without rescoring. Version 3 freezes the new optional 80/20 aggregate weighting.
- A maximum-length trace exceeds the former 2 MB AI envelope. Bounded request/response envelopes now allow 16/18 MB; the CLI prompt omits raw trace frames while preserving per-note summaries and validity. CLI output remains at 2 MB. A maximum-sized trace round-trip checks the margin; no provider call is part of validation.
- Added the actual `dotted-tied-notes` lesson: explanations/counting, two progressive practice examples, a duration quiz and specific listening criteria in en/uk. Both exercises keep positions under all presets and preserve sustain opt-ins. This is original content, not copied repertoire.
